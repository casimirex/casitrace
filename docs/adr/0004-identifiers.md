# ADR 0004: Identifier scheme (D4)

- **Status:** Accepted
- **Date:** 2026-11-10
- **Roadmap ref:** roadmap-v2.md §2

## Context

Records need stable IDs internally and optional GS1 keys externally.

## Decision

Primary keys are UUIDv7 (time-ordered; generated by the application). GS1 keys (GTIN, GLN, SSCC) are optional, validated attributes. A lot code is unique per (org, product).

## Consequences

UUIDv7 keeps B-tree inserts local. GS1 is never required to use the platform.
